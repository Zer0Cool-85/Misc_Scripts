Limitations
The structural scan used tree-sitter-powershell, not the native Microsoft
PowerShell parser. Its grammar does not support the two WinRT-qualified type
literals; their assembly qualifiers were omitted from the in-memory scan only.
The delivered script retains the complete Windows Runtime declarations.
Windows PowerShell 5.1, Task Scheduler, WinRT, theme activation, live accent
refresh, standard-user execution and Autopilot ESP were not executed here.
A Windows pilot remains required. README.md includes a native parser check
and the installation/user-experience pilot procedure.
